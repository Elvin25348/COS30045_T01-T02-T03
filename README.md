# Appliance Energy Consumption - Demonstration Website

## Project Overview
This project is a demonstration website built to learn how to construct interactive web-based data visualizations. This initial phase focuses on building the foundational front-end framework (HTML, CSS, and JavaScript) to create a functional, single-page application experience before uploading and integrating KNIME data visualizations in subsequent tasks.

The website content centers around Australian appliance energy consumption, currently featuring placeholder sections that will later host interactive analytics.

## Features
* **JavaScript-Driven Navigation:** Seamlessly swaps between three core views (Home, Televisions, About Us) without reloading the browser.
* **Interactive Top Navigation:** 
  * Displays a custom power logo in the top-left corner, which routes the user back to the Home page when clicked.
  * Provides intuitive mouse-over (hover) visual feedback.
  * Highlights the current active page to provide location feedback to the user.
* **Custom Theming:** CSS styling is implemented to directly match the color palette extracted from the provided power logo (cream-yellow, light orange, and khaki-brown).
* **Data Visualization Ready:** Includes structured and styled placeholder containers designated for upcoming KNIME data workflows.
